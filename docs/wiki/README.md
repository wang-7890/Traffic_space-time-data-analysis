## 一句话理解项目

手机信令数据记录"谁 + 何时 + 在哪（基站）"，是人的移动轨迹的**代理数据**。
项目按数据流拆成 **6 大模块**，每个模块产出一张结果表接力给下游，最终输出 **6 张业务图 + Streamlit 大屏**：

```
原始信令 → ①数据清洗 → ②出行&驻留识别 → ③出行目的 / ④出行方式 → ⑤实时商圈热力 → ⑥结果可视化 → Dashboard
```
