# 01 · 项目概览

## 1.1 项目定位

**交通时空大数据分析系统**是一个数据分析脚本集合（不是可安装的 Python 包，见 [pyproject.toml](file:///workspace/pyproject.toml#L15-L18)）。

它面向"手机信令数据"这一典型时空大数据，回答四类业务问题：

| 业务问题 | 对应产出 |
| --- | --- |
| 一个人何时在移动、何时在停留？ | 出行/驻留标签（模块②） |
| 停留都是为了什么？ | 出行目的：居住 / 购物 / 旅游 / 其他（模块③） |
| 出行都是怎么去的？ | 出行方式：地铁 / 公交 / 小汽车 / 其他（模块④） |
| 哪里、什么时间最拥挤？ | 商圈实时热力（模块⑤） |

## 1.2 数据背景

手机信令数据是移动通信网络在用户与基站交互时产生的记录，每条记录刻画：

- **谁**：`imsi`（用户标识，脱敏后的手机用户 ID）
- **何时**：`time`（毫秒时间戳）
- **在哪**：`lac_id` / `cell_id`（基站编号，可关联出经纬度）

由于基站覆盖范围即是"位置分辨率"，信令数据本质上是**人的移动轨迹的代理数据**：相邻两条记录间的坐标变化速度，可用来近似推断出行与驻留。

## 1.5 设计原则（技术约定）

项目明确约定了几条"不用现成库、手写核心算法"的原则，用于教学与理解：

1. **不用 sklearn** —— k-means 手写实现（[tr_stage2.py](file:///workspace/project_code/tr_stage2.py)），聚类选 k 也手写轮廓系数 + 邓恩指数。
2. **不用 geopandas** —— 经纬度距离统一用 **Haversine 公式**，聚类阶段用平面欧氏近似加速。
3. **数据 / 代码 / 结果分离** —— 数据放 `data/`，代码放 `project_code/`，结果放 `result/`。
4. **参数集中管理** —— 路径、阈值、窗口大小全在 [config.py](file:///workspace/project_code/config.py)，不写死在模块里。
5. **公共函数复用** —— 读 CSV、编码兜底、Haversine、存结果、matplotlib 中文字体统一写在 [utils.py](file:///workspace/project_code/utils.py)。
6. **契约化接力** —— 各阶段结果表之间按固定列契约传递，改列名必须同步改上下游。
