### 5.1.8 `Harversine(lon1, lat1, lon2, lat2, unit="km")`

（[L104-L112](file:///workspace/project_code/utils.py#L104-L112)）矢量化的 Haversine 球面距离，地球半径 `R=6371.0` km。

- 支持 NumPy 数组广播（多对多距离矩阵）。
- `unit="m"` 返回米，否则返回公里。
- 名称拼写为 `Harversine`（非 `Haversine`），调用时须用此拼写。

```python
a = sin²(Δlat/2) + cos(lat1)·cos(lat2)·sin²(Δlon/2)
c = 2·arcsin(√a)
dist = R · c
```

## 5.2 tr_stage2.py · 核心算法层

模块②阶段2 的手写聚类算法。见 [tr_stage2.py](file:///workspace/project_code/tr_stage2.py)。

### 5.2.1 `pairwise_euclidean(X) -> np.ndarray`

（[L41-L60](file:///workspace/project_code/tr_stage2.py#L41-L60)）点到点欧氏距离矩阵。

- 入参 `X`：`(n,2)` 数组（列 = lon, lat）。
- 出参 `D`：`(n,n)` 矩阵，`D[i,j]` = 点 i 到点 j 的欧氏距离，对角线为 0。
- 实现：`sqrt(((X[:,None,:] - X[None,:,:])**2).sum(axis=2))`，广播一次算好供各 k 复用。

### 5.2.2 `kmeans(X, k, max_iter=100, tol=1e-6) -> (labels, centers)`

（[L63-L106](file:///workspace/project_code/tr_stage2.py#L63-L106)）手写 k-means（NumPy，平面欧氏）。

- 若 `k >= n`：每点自成一簇，直接返回。
- 初始化：`np.random.choice(n, k, replace=False)` 随机取 k 个样本作初始中心。
- 迭代：分配步（最近簇心）→ 更新步（簇内均值；**空簇保留旧中心避免 NaN**）→ 收敛判断（簇心总位移 < `tol` 提前结束）。
- 返回 `labels`（每点簇号）、`centers`（`(k,2)` 簇心）。

### 5.2.3 `silhouette_score(D, labels) -> float`

（[L109-L141](file:///workspace/project_code/tr_stage2.py#L109-L141)）轮廓系数。

- 对每点：`a` = 同簇其他点平均距离，`b` = 最近另一簇平均距离（排除自身），`s=(b−a)/max(a,b)`。
- 只有一个簇返回 0；单点簇 `a` 按 0 处理；`denom==0` 记 0。
- 返回所有点 `s` 的均值，范围 −1~1。

### 5.2.4 `dunn_index(D, labels) -> float`

（[L144-L170](file:///workspace/project_code/tr_stage2.py#L144-L170)）邓恩指数 = 簇间最小距离 / 簇内最大直径。

- 分子遍历簇对取最小（`D[np.ix_(a,b)].min()`），分母遍历簇取最大直径（`D[np.ix_(idx,idx)].max()`）。
- 全重合点时返回 0。值越大越好。

### 5.2.5 `choose_best_k(X) -> (best_labels, best_k)`

（[L173-L197](file:///workspace/project_code/tr_stage2.py#L173-L197)）自动选 k。

- `n < K_MIN(2)`：全归 0 号簇，k=1。
- `k` 从 `K_MIN=2` 到 `min(K_MAX=10, n)`，打分 `轮廓系数 + 0.1 × 邓恩指数`；退化（只聚出 1 簇）给 `-inf`。
- 严格大于才替换（打平保留更小 k）。

### 5.2.6 `main(seed=42) -> dict`

（[L200-L261](file:///workspace/project_code/tr_stage2.py#L200-L261)）阶段2 主入口。逐用户聚类并写 `stage2_cluster.csv`，返回统计字典 `{input_rows, users, n_clusters, n_single_clusters, out_path}`。
