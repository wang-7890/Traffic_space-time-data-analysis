# 06 · 数据契约与字段说明

本项目的核心工程约定是**结果表即接口**：每个模块产出一张表，列名/列序即上下游契约，改列名必须同步改上下游。

---

## 6.1 原始数据（data/raw/，7 个 CSV + 特征值解释.txt）

| 文件 | 规模 | 编码 | 列（按文件实际顺序） | 使用模块 |
| --- | --- | --- | --- | --- |
| `原始数据.csv` | ~532,828 行，无表头，10 列 | UTF-8 | 前 4 列：`time, imsi, lac_id, cell_id`（其余 6 列未使用） | ① |
| `基站经纬度数据.csv` | 49,954 行，无表头 | UTF-8 | `lon, lat, laci`（关联键 `laci = lac_id-cell_id`） | ① |
| `商业区数据.csv` | 104 行，无表头 | UTF-8 | `lon, lat, biz_name` | ⑤ |
| `出行目的静态数据.csv` | 1,273 行，无表头 | **GBK** | `lon, lat, 目的(poi_type), 目的地(poi_name)` | ③ |
| `出行方式静态数据.csv` | 968~986 行，无表头，5 列 | **GBK** | `lon, lat, mode_type, station_name, line_name` | ④ |
| `实时流数据.csv` | 256,212 行，无表头 | UTF-8 | `time, imsi, lon, lat` | ⑤ |
| `hive模块静态数据.csv` | 225 行 | — | 参考用，可不使用 | — |
| `特征值解释.txt` | — | — | 字段说明 | — |

> 关键读写约定：`imsi` / `lac_id` / `cell_id` 必须按**字符串**（`dtype=str`）读取，否则 pandas 推断为数值会丢前导零/精度，与基站表拼 `laci` 时对不上，匹配率变 0。

## 6.2 中间数据（data/processed/）

### 6.2.1 `stage1_dt.csv`（模块②-1 产出）

在清洗后的出行点上加 `speed`，实际落盘列：

| 列 | 类型 | 说明 |
| --- | --- | --- |
| `imsi` | str | 用户 ID |
| `time` | str | `YYYYMMDDHHMMSS` |
| `lac_id` / `cell_id` | str | 基站编号 |
| `lon` / `lat` | float | 经纬度 |
| `speed` | float | 相邻点上一条→当前的瞬时速度（km/h，保留 2 位；异常置空） |

### 6.2.2 `stage2_cluster.csv`（模块②-2 产出）

阶段1 出行点 + 两列：

| 列 | 类型 | 说明 |
| --- | --- | --- |
| `cluster` | int | 簇编号（每用户内从 0 开始，配合 imsi 使用不混淆） |
| `is_single_cluster` | int | 单点簇标记：簇内只有 1 个点记 1，否则 0 |

## 6.3 结果表（result/）

### 6.3.1 `cleaned_data.csv`（模块①）

**固定 6 列，列序固定**：

| # | 列 | 类型 | 说明 |
| --- | --- | --- | --- |
| 1 | `imsi` | str | 用户 ID |
| 2 | `time` | str | `YYYYMMDDHHMMSS`（北京时间） |
| 3 | `lac_id` | str | 基站 LAC |
| 4 | `cell_id` | str | 基站 Cell |
| 5 | `lon` | float | 经度 |
| 6 | `lat` | float | 纬度 |

### 6.3.2 `stage3_label.csv`（模块②-3）

`cleaned_data.csv` 6 列 + `label`：

| 列 | 类型 | 取值 | 说明 |
| --- | --- | --- | --- |
| `label` | int | 0 / 1 | **0 = 驻留，1 = 出行** |

### 6.3.3 `purpose_result.csv`（模块③）

**每驻留段一行**。列：

| 列 | 说明 |
| --- | --- |
| `imsi` | 用户 ID |
| `seg_id` | 驻留段编号（用户内） |
| `start_time` / `end_time` | 段起止时间（`YYYYMMDDHHMMSS`） |
| `points` | 段内点数 |
| `center_lon` / `center_lat` | 段中心经纬度 |
| `start_dt` / `end_dt` | 解析后的 datetime |
| `duration_hours` | 停留时长（小时） |
| `start_hour` / `end_hour` | 起止小时 |
| `purpose_by_time` | 时间规则粗判结果（居住/购物/旅游/其他） |
| `nearest_poi_name` / `nearest_poi_type` | 最近 POI 的名称/类型 |
| `nearest_dist_m` | 到最近 POI 的距离（米） |
| `match_success` | POI 是否匹配成功（bool，阈值 1000m） |
| `final_purpose` | **最终目的**（POI 优先，时间规则兜底） |

### 6.3.4 `mode_result.csv`（模块④）

**每出行段一行**，输出 14 列：

| 列 | 说明 |
| --- | --- |
| `imsi` | 用户 ID |
| `seg_id` | 出行段编号（用户内） |
| `start_time` / `end_time` | 段起止时间 |
| `point_count` | 段内点数（≥2） |
| `lon_start` / `lat_start` / `lon_end` / `lat_end` | 段起终点坐标 |
| `avg_speed` | 段内平均速度（km/h） |
| `mode_speed` | 速度粗判结果（其他/公交/地铁或小汽车） |
| `subway_hit_count` | 命中地铁站点数（500m 内） |
| `bus_hit_count` | 命中公交站点数（500m 内） |
| `final_mode` | **最终方式**（地铁/公交/小汽车/其他） |

### 6.3.5 `heatmap_result.csv`（模块⑤）

| 列 | 说明 |
| --- | --- |
| `minute` | 当日分钟序号（0~1439） |
| `biz_name` | 商圈名称 |
| `count` | 该分钟商圈过去 10 分钟累计人次（滑窗） |
| `hour` | 小时（`minute // 60`），供可视化 |

## 6.5 通用数据约定

| 约定 | 内容 |
| --- | --- |
| **时间格式** | 统一 `YYYYMMDDHHMMSS` 字符串（无时区；毫秒 UTC 时间戳已按 +8h 转北京时间） |
| **时间解析** | 需要时间运算用 `utils.parse_time` 转回 datetime |
| **ID 类型** | `imsi` / `lac_id` / `cell_id` 一律字符串读写，防丢前导零 |
| **结果编码** | 结果 CSV 统一 `utf-8-sig` 写出（Excel 打开中文不乱码） |
| **原始编码** | 读原始 CSV 用 `_read_csv_any_encoding`（UTF-8 失败回退 GBK） |
| **列序固定** | `cleaned_data.csv` 6 列顺序即下游契约 |
| **标签语义** | `label` 0=驻留 / 1=出行 |
| **来源模块** | 见 [02-架构与数据流 · 接力契约](02-架构与数据流.md#23-模块接力契约一句话版) |

## 6.6 数据流字段血缘（简版）

```
原始数据.csv ──(①)──> cleaned_data.csv[imsi,time,lac_id,cell_id,lon,lat]
                                   │
                                   ├─(②-1)→ stage1_dt.csv[...,+speed]
                                   │           │
                                   │           └─(②-2)→ stage2_cluster.csv[...,+cluster,is_single_cluster]
                                   │                       │
                                   └───────────────────────┴─(②-3)→ stage3_label.csv[...,+label]
                                                                       │
                                                       ┌───────────────┴───────────────┐
                                                       │(③)                            │(④)
                                                       ▼                               ▼
                                       purpose_result.csv[+final_purpose]   mode_result.csv[+final_mode]

实时流数据.csv + 商业区数据.csv ──(⑤)──> heatmap_result.csv[minute,biz_name,count,hour]

4 张结果表 ──(⑥)──> result/figures/*.png ──> Dashboard
```
