# 03 · 目录与配置说明

## 3.1 目录结构

```
data-analysis-project/
├── data/                        # 数据目录（不入库，太大）
│   ├── raw/                     # 原始数据（7 个 CSV + 特征值解释.txt）
│   └── processed/               # 模块2 中间结果（stage1_dt.csv、stage2_cluster.csv）
├── project_code/                # 代码目录（6 大模块）
│   ├── config.py                # 全局配置：路径、阈值、参数（改参数只改这里）
│   ├── utils.py                 # 公共工具：读 CSV 编码兜底、Haversine、存结果、中文字体
│   ├── check_data.py            # 数据完整性检查（跑之前先执行）
│   ├── data_clean.py            # ① 数据清洗（9 条规则）
│   ├── tr_stage1.py             # ②-1 阶段1 预处理（速度粗筛出行点）
│   ├── tr_stage2.py             # ②-2 阶段2 聚类（手写 k-means，轮廓系数+邓恩指数选 k）
│   ├── tr_stage3.py             # ②-3 阶段3 业务判定（出行/驻留标签）
│   ├── purpose.py               # ③ 出行目的（时间规则 + POI 匹配，POI 优先）
│   ├── mode.py                  # ④ 出行方式（速度 + 地铁/公交 POI 匹配）
│   ├── heatmap.py               # ⑤ 实时商圈热力（10 分钟滑窗）
│   ├── visualize.py             # ⑥ 结果可视化（6 张业务图）
│   ├── Dashboard.py             # Streamlit 大屏（需额外装 streamlit）
│   ├── main.py                  # 主入口（一键串联各模块）
│   └── __init__.py              # 包标识
├── result/                      # 结果目录（*.csv 不入库，figures/*.png 入库）
│   ├── cleaned_data.csv         # ① 清洗结果（6 列标准表）
│   ├── stage3_label.csv         # ② 出行/驻留标签（0=驻留，1=出行）
│   ├── purpose_result.csv       # ③ 目的结果（每驻留段一行）
│   ├── mode_result.csv          # ④ 方式结果（每出行段一行）
│   ├── heatmap_result.csv       # ⑤ 热力结果（minute, biz_name, count, hour）
│   └── figures/                 # ⑥ 6 张业务图（png）
├── notebooks/                   # Jupyter 笔记本（数据探查）
├── docs/wiki/                   # 本 Code Wiki 文档
├── pyproject.toml               # 依赖清单与 uv 配置（以它为准）
├── uv.lock                      # uv 锁文件
├── requirements.txt             # pip 依赖清单
├── .python-version              # 固定 Python 3.14
└── README.md                    # 项目说明
```

## 3.3 config.py 全量常量说明

### 3.3.1 路径常量

| 常量 | 值（相对项目根） | 说明 |
| --- | --- | --- |
| `PROJECT_ROOT` | `Path(__file__).resolve().parent.parent` | 项目根目录，基于 `__file__` 锚定 |
| `DATA_DIR` | `PROJECT_ROOT / 'data'` | 数据目录 |
| `RAW_DIR` | `data/raw` | 原始数据目录 |
| `PROCESSED_DIR` | `data/processed` | 中间结果目录 |
| `RESULT_DIR` | `result` | 结果目录 |
| `FIGURES_DIR` | `result/figures` | 图表目录 |

### 3.3.2 原始数据文件名 `RAW_FILES`

| 键 | 文件名 | 规模 / 编码 | 用途 |
| --- | --- | --- | --- |
| `signal` | `原始数据.csv` | ~53 万行，UTF-8，无表头，10 列 | 模块①主输入 |
| `station` | `基站经纬度数据.csv` | 49,954 行，列序 lon,lat,laci | 模块①补经纬度 |
| `biz` | `商业区数据.csv` | 104 行，列序 lon,lat,biz_name | 模块⑤商圈范围 |
| `purpose` | `出行目的静态数据.csv` | 1,273 行，**GBK**，列序 lon,lat,目的,目的地 | 模块③ POI |
| `mode` | `出行方式静态数据.csv` | 968~986 行，**GBK**，5 列 | 模块④站点 |

### 3.3.5 清洗参数（模块①）

| 常量 | 值 | 含义 |
| --- | --- | --- |
| `TARGET_DATE` | `'20181003'` | 规则5：只保留目标日 |
| `MIN_POINTS_PER_USER` | `20` | 规则9：当天点数不足的用户删除 |
| `SAMPLE_ROWS` | `20000` | 教学抽样目标行数；`0` = 全量（手写 k-means 慢，慎用） |
| `RAW_TIMEZONE_OFFSET_HOURS` | `8` | 规则4：毫秒 UTC 时间戳转北京时间时差 |

### 3.3.6 阶段1 速度参数

| 常量 | 值 | 含义 |
| --- | --- | --- |
| `SPEED_THRESHOLD` | `8` | 低于该速度（km/h）视为静止 → 不算出行点 |
| `ABNORMAL_SPEED` | `200` | 高于该速度视为基站跳跃假高速 → speed 置空（不删行） |

### 3.3.7 阶段3 业务判定参数

| 常量 | 值 | 含义 |
| --- | --- | --- |
| `CLUSTER_DIST_THRESHOLD` | `1000` | 首/中/尾三点到簇中心距离阈值（米） |
| `TIME_SPAN_THRESHOLD` | `2` | 簇首末时间跨度阈值（小时） |

### 3.3.8 模块③ 出行目的参数

| 常量 | 值 | 含义 |
| --- | --- | --- |
| `LIVING_DURATION_THRESHOLD` | `4` | 居住：停留时长阈值（小时） |
| `PURPOSE_MATCH_THRESHOLD` | `1000` | POI 最近邻匹配成功阈值（米） |
| `SHOPPING_START_HOUR` / `SHOPPING_END_HOUR` | `9` / `21` | 购物时间窗 |
| `TOUR_START_HOUR` / `TOUR_END_HOUR` | `9` / `17` | 旅游时间窗（购物窗的子集） |

> ⚠️ `LIVING_DURATION_THRESHOLD` 在 config 中已定义，但 [purpose.py](file:///workspace/project_code/purpose.py#L47) 的业务判定中硬编码为 `4`，`PURPOSE_MATCH_THRESHOLD` 亦未被引用（模块③内用局部 `MATCH_THRESHOLD = 1000`）。改阈值时需同步核对模块内常量。

### 3.3.9 模块④ 出行方式参数（定义在模块内，不在 config）

这些参数定义在 [mode.py#L22-L26](file:///workspace/project_code/mode.py#L22-L26)：

| 常量 | 值 | 含义 |
| --- | --- | --- |
| `MATCH_THRESHOLD` | `500` | 站点匹配阈值（米） |
| `SUBWAY_MIN_POINTS` | `2` | 命中 ≥2 个地铁站 → 判地铁 |
| `BUS_MIN_POINTS` | `3` | 命中 ≥3 个公交站 → 判公交 |
| `SPEED_OTHER` | `12` | 平均速度 <12 km/h → "其他" |
| `SPEED_BUS` | `20` | 12~20 → 公交档；>20 → 地铁/小汽车档 |
