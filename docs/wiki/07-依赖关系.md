## 7.1 第三方依赖

依赖清单以 [pyproject.toml](file:///workspace/pyproject.toml) 为准（`requirements.txt` 为 pip 版，`uv.lock` 为锁文件）。

| 库 | 最低版本 | 用途 | 使用位置 |
| --- | --- | --- | --- |
| `pandas` | — | 表格读写、groupby、merge、聚合 | 全部模块 |
| `numpy` | — | 广播距离矩阵、手写 k-means、滑窗统计 | 全部模块 |
| `matplotlib` | — | 6 张业务图含 3D | 模块⑥ |
| `loguru` | ≥0.7.3 | 可视化模块日志 | [visualize.py](file:///workspace/project_code/visualize.py) |
| `haversine` | ≥2.9.0 | 热力模块距离计算 | [heatmap.py](file:///workspace/project_code/heatmap.py#L9) |
| `streamlit` | ≥1.66.0 | Dashboard 大屏 | [Dashboard.py](file:///workspace/project_code/Dashboard.py) |

**版本/环境约束**：

- Python `>=3.13`（[pyproject.toml#L5](file:///workspace/pyproject.toml#L5)），`.python-version` 固定 3.14。
- 项目**不是可安装包**：`[tool.uv] package = false`（[pyproject.toml#L17-L18](file:///workspace/pyproject.toml#L17-L18)），uv 只做依赖管理。

> 注：`requirements.txt` 中 `streamlit` 被注释掉（按需安装），而 `pyproject.toml` 中已列入。以 `pyproject.toml` 为准。
> 另：`utils.py` 的备用距离函数用 NumPy 手写，与 `haversine` 库并存——热力模块用库，其余模块用 `utils.Harversine`。

## 7.2 代码导入依赖图

**单向依赖**：业务模块 → 配置层/工具层；编排/展示层 → 业务模块 + 配置层/工具层。业务模块之间**不互相 import**（各自独立可单跑）。

```
                      ┌─────────────────────┐
                      │      config.py       │  ← 被所有模块依赖
                      └──────────┬──────────┘
                                 │ (路径/文件名/参数)
                      ┌──────────▼──────────┐
                      │      utils.py        │  ← 被多数模块依赖
                      └──────────┬──────────┘
                                 │ (load_csv/save_result/Harversine/...)
        ┌──────────┬──────────┬──┴───────┬──────────┬──────────┐
        ▼          ▼          ▼          ▼          ▼          ▼
  data_clean  tr_stage1   tr_stage2  tr_stage3  purpose     mode
        │          │          │          │          │          │
        └──────────┴──────────┴──────────┴──────────┴──────────┘
                                 │
              ┌──────────────────┼──────────────────┐
              ▼                  ▼                  ▼
          heatmap           visualize          Dashboard
              │                  │                  │
              └──────────────────┼──────────────────┘
                                 ▼
                              main.py  (编排，import 全部业务模块)
```

**额外 POI 静态数据依赖**：

- 模块③ 依赖 `出行目的静态数据.csv`（GBK）。
- 模块④ 依赖 `出行方式静态数据.csv`（GBK）。

**依赖顺序（必须满足）**：

```
check_data → data_clean → tr_stage1 → tr_stage2 → tr_stage3
                                                   ├→ purpose
                                                   └→ mode
                                    heatmap（独立，可与②并行）
                                                   └→ visualize → Dashboard
```

> 阶段②-2 内部有 **fail-fast** 保护：若 `stage1_dt.csv` 不存在或为空，直接抛 `FileNotFoundError` 并提示先运行 `tr_stage1.py`（见 [tr_stage2.py#L207-L222](file:///workspace/project_code/tr_stage2.py#L207-L222)）。
> 模块⑥ 有 **软依赖** 保护：结果表缺失只警告并跳过对应图，不中断（见 [visualize.py#L193-L199](file:///workspace/project_code/visualize.py#L193-L199)）。

## 7.4 依赖风险点小结

| 风险 | 位置 | 说明 |
| --- | --- | --- |
| 阶段1 文件名不一致 | [tr_stage1.py#L75](file:///workspace/project_code/tr_stage1.py#L75) vs [config.py#L41-L44](file:///workspace/project_code/config.py#L41-L44) | 实际写 `stage1_dt.csv`，`PROCESSED_FILES['trajectory']` 定义 `trajectory_points.csv` 未被引用 |
| config 参数在模块内被硬编码 | [purpose.py#L47](file:///workspace/project_code/purpose.py#L47)、[mode.py#L22-L26](file:///workspace/project_code/mode.py#L22-L26) | `LIVING_DURATION_THRESHOLD` / 方式阈值未从 config 取，改 config 不生效 |
| Dashboard 依赖图片存在 | [Dashboard.py#L43-L65](file:///workspace/project_code/Dashboard.py#L43-L65) | 硬编码图片名，需先跑模块⑥ |
| 模块③④⑤ 无独立容错 | purpose/mode | 异常会直接抛出，由 `main.py` 统一捕获 |
