## 8.2 数据准备

原始数据**不上传 Git**（`data/` 已在 [.gitignore](file:///workspace/.gitignore#L222) 忽略），克隆代码后需手动获取：

1. 从群/网盘下载数据包。
2. 解压后把所有 `.csv` 放到 **`data/raw/`** 文件夹。
3. 放置后目录结构**必须**是：

   ```
   data-analysis-project/
   ├── data/
   │   └── raw/
   │       ├── 原始数据.csv          # 约 53 万行，UTF-8，无表头，10 列
   │       ├── 基站经纬度数据.csv     # 49,954 行，关联键 laci = lac_id-cell_id
   │       ├── 商业区数据.csv         # 104 行，实时热力用
   │       ├── 出行目的静态数据.csv   # 1,273 行，GBK 编码
   │       ├── 出行方式静态数据.csv   # 968 行，GBK 编码，5 列
   │       ├── 实时流数据.csv         # 256,212 行，滑窗统计用
   │       ├── hive模块静态数据.csv   # 225 行，参考用
   │       └── 特征值解释.txt
   ```

4. **常见错误自查**：

   - ❌ 数据还留在"下载"文件夹，没挪进项目里。
   - ❌ 解压时多套一层：`data/raw/数据包/原始数据.csv`（要的是 `data/raw/原始数据.csv`）。
   - ❌ 文件名被改：重复下载会变成 `原始数据 (1).csv`，请改回原名。

5. **验证**：项目根目录运行 `python project_code/check_data.py`，输出 `[OK] 数据完整` 即成功。

> 读数据注意：`lac_id` / `cell_id` / `imsi` 必须按**字符串**读取（`dtype=str`）；出行目的/出行方式静态数据是 **GBK 编码**，`utils.load_csv` 会自动兜底。

## 8.3 运行方式

三种运行方式，均在**项目根目录**下执行（脚本自带路径引导，从任意目录运行也可，但根目录最稳）。

### 方式一：逐模块运行（推荐，便于定位问题）

模块之间有接力关系，按顺序执行（注释标注了每步吃哪张表）：

```bash
python project_code/check_data.py   # 0. 检查数据是否齐备

python project_code/data_clean.py   # ① 数据清洗 → result/cleaned_data.csv
python project_code/tr_stage1.py    # ②-1 预处理 → data/processed/stage1_dt.csv
python project_code/tr_stage2.py    # ②-2 聚类 → data/processed/stage2_cluster.csv
python project_code/tr_stage3.py    # ②-3 业务判定 → result/stage3_label.csv

python project_code/purpose.py      # ③ 出行目的（吃 stage3_label + POI 静态数据）
python project_code/mode.py         # ④ 出行方式（吃 stage3_label + 方式静态数据）
python project_code/heatmap.py      # ⑤ 实时热力（吃实时流 + 商业区数据）
python project_code/visualize.py    # ⑥ 可视化（吃 4 张结果表 → 6 张图）
```

### 方式二：一键跑通 main.py

```bash
python project_code/main.py         # 按数据流顺序串联 8 个模块
```

`main.py` 的行为：

- 每个模块单独计时（`Timer`）；
- 单模块失败只打印 traceback 并**继续后续模块**；
- 跑完自动核对 7 张结果 CSV + 6 张图的产出情况（缺失的标 `[缺失]`）。

### 方式三：Dashboard 大屏

```bash
streamlit run project_code/Dashboard.py   # 需先安装 streamlit、先生成 6 张图
```

## 8.5 性能与参数调优

| 关注点 | 做法 |
| --- | --- |
| 手写 k-means 慢 | 默认 `SAMPLE_ROWS=20000`（整用户抽样）；调大前先评估耗时。全量设 `SAMPLE_ROWS=0` |
| 聚类候选 k 范围 | [tr_stage2.py#L37-L38](file:///workspace/project_code/tr_stage2.py#L37-L38) `K_MIN` / `K_MAX`（默认 2~10） |
| 热力内存 | [heatmap.py#L15](file:///workspace/project_code/heatmap.py#L15) `BATCH_SIZE`（默认 10000，分批广播） |
| 滑窗大小 | [heatmap.py#L13](file:///workspace/project_code/heatmap.py#L13) `WINDOW_MINUTES`（默认 10） |

参数集中位置见 [03-目录与配置说明 · 修改参数指引](03-目录与配置说明.md#34-修改参数的改哪里指引)。

## 8.6 常见问题排错

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `check_data.py` 报 `[缺少数据]` | `data/raw/` 缺文件或路径不对 | 按 8.2 重新放置；注意别多套一层目录 |
| `load_csv` 抛 `FileNotFoundError` | 原始文件缺失 | 同上，按 README 数据准备章节放好 |
| 基站关联后行数骤降 / 匹配率 ~0 | ID 列被按数值读丢前导零 | 确认用 `dtype=str` 读取 `imsi/lac_id/cell_id` |
| 模块③ POI 全被删光 | POI 列序写错（把中文列当数字列） | 列序必须为 `lon,lat,poi_type,poi_name`（见 [purpose.py#L110-L113](file:///workspace/project_code/purpose.py#L110-L113)） |
| 模块②-2 报"未找到阶段1 中间结果" | 没先跑 `tr_stage1.py` | 先运行阶段1 |
| 中文图乱码 | 未设置中文字体 | `visualize` 已调 `setup_style()`；非 Windows 环境需装 SimHei/文泉驿等中文字体 |
| Dashboard 图缺失 | 未先生成 6 张图 | 先运行 `python project_code/visualize.py` |
| `streamlit` 命令不存在 | 未安装 | `pip install streamlit` |

## 8.7 扩展与维护约定

- 新增分析步骤时，遵循"**一张结果表 → 下游**"的模式，并把文件名/参数登记到 [config.py](file:///workspace/project_code/config.py)。
- 公共逻辑（读/写/距离/绘图）放 [utils.py](file:///workspace/project_code/utils.py)，不要各写一份。
- ID 类字段一律字符串读写；结果 CSV 一律 `utf-8-sig` 写出。
- 改动结果表列名时，**必须同步**修改下游读取处的列引用。
- 若在 `main.py` 里新增模块，需同时：
  1. 加入 `MODULES` 列表（[main.py#L36-L45](file:///workspace/project_code/main.py#L36-L45)）；
  2. 若是新结果表，登记到 `RESULT_CSVS`；若是新图，登记到 `RESULT_FIGS`。
